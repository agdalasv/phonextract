PhoneXtract

Herramienta de Inteligencia de Números Telefónicos

Herramienta OSINT poderosa para obtener información sobre cualquier número telefónico a nivel mundial. Ideal para propósitos educativos e investigación en seguridad.

Comenzar

Características

Ubicación

Obtén la ubicación (estado/región) del número telefónico basado en prefijos.

Operador

Detecta el operador móvil (Airtel, Jio, AT&T, Vodafone, etc.).

Tipo de Teléfono

Identifica si es Móvil, Línea Fija, VoIP o Toll Free.

Zona Horaria

Obtén la zona horaria del número telefónico.

WhatsApp

Verifica si el número está registrado en WhatsApp.

Reporte Spam

Consulta bases de datos públicas de spam y reportes.

Soporte Global

Funciona con números de todos los países del mundo.

Redes Sociales

Busca el número en Facebook, Instagram, Telegram, LinkedIn.

Reportes

Genera reportes detallados en formato texto.

Instalación 

# Arch Linux
sudo pacman -Syu
sudo pacman -S python python-pip git

git clone https://github.com/agdalasv/phonextract.git
cd phonextract
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python phonextract.py
# Ubuntu / Debian
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip python3-venv git -y
